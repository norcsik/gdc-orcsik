# Graphic Design Club Landing Page

This project is a static single-page website built from the approved Figma design for the Graphic Design Club.

## Project structure

- `index.html` — page structure and semantic sections
- `styles/styles.css` — design styling, layout, and responsive behavior
- `js/main.js` — light enhancement script for form interaction
- `assets/` — images, icons, and decorative graphics used in the layout

## Notes

- The design is implemented as a desktop-first landing page.
- Responsive behavior is included for narrower screens.
- Asset references are local project paths rather than temporary Figma URLs.
